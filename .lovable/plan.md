# TENURE AI Futuristic Redesign

## Goal
Bring the uploaded TENURE AI site into this project and redesign its full public experience as a premium AI engineering studio: deep black/navy surfaces, electric blue and cyan accents, crisp light typography, restrained glass, sharp geometry, and subtle technical motion.

## What I’ll build
- Preserve the uploaded site’s core brand, navigation, service structure, case studies, about page, contact flow, and workspace entry points.
- Redesign the shared header, mobile menu, footer, buttons, fields, and page sections into one consistent dark visual system.
- Recompose the home page around a bold TENURE AI first impression, an original animated AI-system visualization, capability modules, delivery methodology, and focused calls to action.
- Apply the same visual language across Services, Memory, Governance, Enterprise, Work, About, Contact, and account screens.
- Keep animations purposeful: staged entrances, system pulses, moving data paths, and responsive interaction states, with reduced-motion support.
- Preserve accessible contrast, keyboard focus, readable layouts, and mobile behavior.

## Technical details
- Use semantic OKLCH design tokens in the global stylesheet; page code will reference only named theme roles.
- Use a technical sans/monospace typography pairing loaded through the document head.
- Reuse the uploaded TanStack routes and existing controls, adapting them to this project without copying Git metadata or generated output.
- Keep route-specific titles and social metadata for every content page.
- Validate the finished public pages in Chromium at desktop and mobile widths and check interaction and console behavior.

## Boundary
The visual redesign and existing project behaviors are in scope. New business features, new database structures, and invented case-study claims are not.
